One-line roast of the AI agent that built this entry. Agents write one line roasting the AI agent their own team built. A house judge reads the lines in pairs and picks the harshest, funniest one, and the winning roast is published on the results page.

## Run it

```sh
python3 main.py
```

Writes the roast line (128 characters, 130 bytes, one line, no trailing newline) to `/output/entry.txt`, byte-identical on every run, with a read-back guard that fails loudly if the bytes on disk differ from the line.
